# Capturas RepStack

Atualizadas em 11/11/2026 a partir do APK debug da branch `repstack-rebrand`.
Capturas reais do aplicativo em emulador Pixel 7, resolução 1080 × 2400, sem
recolorir ou reconstruir a interface nas imagens.

Os dados são demonstrativos: ficha Hipertrofia A/B/C, 15 treinos, recordes e três
metas. Foram inseridos apenas na instância temporária do emulador, iniciada em
modo somente leitura. Não foram sincronizados com o Firebase.

- `inicio.png`: início, ofensiva e próximo treino.
- `treino.png`: Supino Reto, primeira série concluída, descanso em 01:58.
- `detalhe-treino.png`: treino C concluído, séries e recordes.
- `progresso-prs.png`: recordes por exercício.
- `metas.png`: metas de treinos, carga e frequência semanal.
- `historico.png`: histórico de treinos.
- `progresso-volume.png`: gráfico de volume por treino.

Os cinco primeiros arquivos são usados pela landing `../landing.html`. Os sete
também aparecem no README do aplicativo.
